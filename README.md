# Exam schedule platform: public demo

Public static demo of the exam schedule platform (Faculty of Science, Sohag University). Preview only.

- Demo data only. No real student data. The logins shown on the login page are fake demo accounts, not real security.
- Everything is stored in each visitor's own browser (localStorage). Changes are not shared between people.
- This is not the production system. The project's real code lives in a separate private repository.
